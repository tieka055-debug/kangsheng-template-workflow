# 康生图纸：技术内容优先

将可靠原图转换为用户认可的康生视觉样式。品牌模板不是技术数据来源。顺序：完整、准确、可读，然后美观和速度。

## 本项目不可变要求

- 保留全部产品视图、共享尺寸线、剖面、PCB 图、尺寸/公差/单位、性能说明、材料/镀层、系列型号—尺寸表及脚注。PART NO. / DIM A/B/C 表是核心内容，紧贴旧标题栏也必须保留全部行列。
- 原图中的数值、正负号、小数点、型号不猜补、不截断、不自动省略。截图被遮挡或原图字迹不清时标记 REVIEW，并寻找更可靠原件。
- 可以省略右上**空白**修订表；有实际修订记录时先保留。不要为了保空表缩小或裁切产品内容。
- 冻结品牌背景、Logo 和样式，不冻结比例、默认公差、单位、页码、投影法、版本和产品名称。逐图核对技术字段。
- 移动完整内容组，共享尺寸线的视图合为一组。拥挤时先去空修订表；仍不够则提出分页/加大画幅方案，不静默删内容。
- 原件只读；候选图与历史成品分目录。现有成品或飞书附件不能仅因名称相同就当原件。

## 开始时

1. 读取 [生产与验收流程](references/workflow.md)。定位实际仓库、原图、用户认可母版和运行代码；记录版本差异，不根据旧 README 自动重跑。
2. 建立源页和技术内容清单，包括每张表的全部行列，以及每个视图。检查所有页，不只第一页。
3. 将未知格式转人工确认。先用失败样板验证：漏材料表的 5P、断层拼版、含 PART NO./DIM 表的复杂系列图，再同族小批处理。
4. 优先保留矢量；扫描件只能忠实搬运已确认的内容，不凭 OCR 重新编造数值。禁止以关键词、颜色、固定边缘坐标直接判定删除。

## 验收与发布

- 独立检查未清理原图，不以生成器自己的删除掩码作为完整性真值。
- 全页检查布局、局部检查文字/线条、实际尺寸检查可读性；系列表逐行逐列对照；检查重复、缺失、遮挡及多页遗漏。
- 读取 [门禁记录格式](references/release-gate.md)，为**当前文件哈希**记录证据及人工/代理复核结论。
- 运行本 Skill 的 `scripts/release_gate.py MANIFEST`。只有退出码 0 才能进入发布准备。该工具仅检查证据记录完整性和文件一致性，不代替工程正确性判断，也不会上传。
- 用户批准样板后才扩大同族处理；实际发布仍需当前任务明确授权。读取 [历史故障及边界](references/legacy.md)，不要直接使用旧上传脚本。
- 交付时分清：生成成功、核查通过、用户确认、上传成功、回读一致。不得统称“全部完成”。

## 资源位置

本 Skill 可独立复制使用；脚本仅依赖 Python 3 标准库。品牌资产在项目仓库根目录的 `asset_*` 文件中。复制 Skill 不等于带走资产，应由任务显式指定原图、母版和输出位置。不要依赖 `/tmp` 保存唯一原件，不硬编码个人目录、凭证或飞书记录 ID。
