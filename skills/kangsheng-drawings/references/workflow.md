# 制作、核查、回归

## 源图台账

每项记录稳定产品 ID、源附件 ID、SHA-256、来源、原页数、图号、型号范围，以及预期的输出页/附件数。区分供应商原件、已品牌化成品、转换中间件、照片。历史文件名、行号、状态 ok 都不代表可信原件或验收通过。

原始 PDF/DWG 保持不变；转换为候选图前检查原件本身是否缺字、缺图。DWG 字库错误不能靠改颜色修复，须找到正确字库/可靠导出件并核对所有页。

## 内容清单（先于删除）

每个源页建立独立的必保组 ID：
- 每个视图及关联尺寸、公差、箭头、剖面符号；共享尺寸的视图不拆开。
- PCB 焊盘、孔位、坐标、推荐布局及 PCB 专用公差/备注。
- 每张型号尺寸表（PART NO./DIM A/B/C 等），清点全部表头、行、列、单位、脚注；记录逐格值或可靠原图定位。
- 材料/零件/BOM、镀层、性能参数、温度和技术说明。
- 有效合规声明及技术标题栏字段。

允许移除项另列清单、准确边界与理由。未知区域默认保留待复核。旧标题栏内的技术数据先迁移并确认，再处理旧品牌/签字等非产品内容；“靠近标题栏”不是删除依据。

## 版式处理

分族：普通单页、复杂系列、规格表密集、双图拼版、超大画幅、DWG、照片、多页。各族配置保存坐标系、页旋转、组边界、实际变换矩阵、允许移除区域、技术字段映射及源哈希。

禁止把 A4 横版固定边缘套在竖页或大画幅上。方向必须通过可读文字确认。双图拆分先核对完整图框与内容清单，拆后每一组都有去处；不能单凭最低墨量列判断安全切缝。

布局优先腾出空修订表区域。矢量保持矢量；照片适度增显也应并排检查浅线/点号是否丢失。重要文字对比度不得被背景压低。不要统一把所有尺寸文字改成浅金色。

母版中的 3:1、默认公差、产品名称不是通用值。重排缩放须核实标注比例；多视图不同缩放时提出明确标注方案，交工程负责人确认，不擅自替换技术规范。

## 独立验收

对未经过清除的原图建立清单。按真实变换反向比较内容区域；既检遗漏，也检重复和裁剪。像素覆盖和 OCR 只是提示，不是“一笔不缺”的证明。

逐图核对：
1. 所有源页、内容组都有目标位置。
2. 尺寸数字、点号、符号、单位正确。
3. 每张参数/型号表的所有行列及对应关系正确。
4. 材料、说明、性能、默认公差等完整。
5. 技术标题栏字段正确。
6. 无重叠、切边、乱码、重复；全页和局部可读。
7. 当前输出与核查证据哈希一致。

新源图/新布局/新代码修改后，旧验收失效。回归用固定原件样本，至少涵盖上述风险；不要把历史 PASS 原样复用到新文件。

## 发布边界

门禁通过后依然不自动发布。获得本次发布授权，先保存线上旧附件映射；记录级完整合并，不用单附件/成功子集覆盖其他附件。保留供应商原图列；只有指定的候选/替换列可写。串行单一发布者，有冲突即停。

失败停止该记录提交并保留旧集合。发布后读回并下载验证内容/哈希和附件数量；记录新旧映射以便回滚。旧脚本并不实现这些事务保证，不直接复用。
